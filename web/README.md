# GoreeCloud Contacts — web application

This is a browser-native, locally persistent Contacts app with no external JS packages, CDN, remote fonts, telemetry or network APIs. It includes GoreeCloud UI tokens and the verified official GoreeCloud umbrella logo.

Run from repository root: python3 web/server.py --port 8765. Visit http://127.0.0.1:8765/. This loopback-only static development server is not an authenticated contact-hosting or public production service.

Implemented in source: create/edit/delete, favorites, accent-insensitive search, accessible dialogs and controls, responsive light/dark design, atomic no-overwrite import of strict JSON v1 or the limited vCard 3.0 profile already exported by this app, user-confirmed unencrypted JSON backup and limited vCard export. The vCard importer rejects unsupported rich fields rather than silently dropping information; contact favorites are not restored from vCards. Contacts persist only in the current browser profile's IndexedDB. Each manual JSON/vCard export reads a fresh validated IndexedDB snapshot at export time, avoiding stale-tab backups; concurrent edits immediately after that snapshot are not included. The browser now emits a contact-free BroadcastChannel invalidation marker after committed local changes and also refreshes on visibility/focus, so other tabs in the **same origin and browser profile** can refresh their directory without exchanging contact details. Stale editors and delete confirmations still fail closed against their prior contact snapshot. A second real Chrome acceptance scenario exercises two actual browser tabs against the same IndexedDB and verifies stale editor saves and deletion confirmations are rejected after the other tab updates a contact. This is synthetic-only and does not establish cross-profile or cross-device sync.

Caution: Browser-profile data is not encrypted by this app. Clearing browser data can delete it, and anyone who controls the same unlocked profile can access it. The app never automatically syncs contacts with Linux, Android or a server. Exports create sensitive plaintext files.

Tests: node --test web/tests/*.test.mjs; python3 -m unittest discover -s web/tests -p test_*.py. Native browser visual and assistive-technology acceptance remain open. See docs/PLATFORMS.md in the parent repository.
